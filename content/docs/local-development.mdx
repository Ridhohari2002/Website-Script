These instructions run the project on a local machine. They do not deploy anything.

## Requirements

- Node.js 20 or newer
- npm 10 or newer
- PostgreSQL only if you intend to exercise API routes that touch the database

## First run

```bash
npm install
cp .env.example .env.local
npm run dev
```

The public site is then available at `http://localhost:3000`.

Windows shells can use `Copy-Item .env.example .env.local` instead of `cp`.

## Environment

Copy `.env.example` to `.env.local` and fill in only what you need. Never commit `.env.local` or paste its values into an issue.

| Variable | Needed for |
| --- | --- |
| `APP_URL` | Absolute redirects and origin checks. Defaults to `http://localhost:3000`. |
| `NEXT_PUBLIC_SITE_URL` | Canonical public origin used by metadata, canonical links, sitemap, and robots. Required for a production build; must be `https://`. |
| `DATABASE_URL` | API routes that read or write PostgreSQL. Not needed for `next build`. |
| `SESSION_HMAC_SECRET` | Session token hashing and CSRF derivation. Required in production. |
| `RATE_LIMIT_HMAC_SECRET` | Privacy-preserving rate-limit bucket identifiers. Required in production. |
| `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`, `DISCORD_REDIRECT_URI` | Discord OAuth. The login route returns `503` when these are missing. |
| `MIDTRANS_*` | Reserved. Payments are not authorized or implemented. |

`DISCORD_REDIRECT_URI` must exactly equal `${APP_URL}/api/auth/callback`.

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the local development server. |
| `npm run build` | Create a production build. No database credentials are required. |
| `npm run typecheck` | Run TypeScript without emitting files. |
| `npm run lint` | Run ESLint across the repository. |
| `npm run format:check` | Verify Prettier formatting. |
| `npm test` | Run the Vitest unit suite. |
| `npm run db:migrate` | Apply migrations to the configured database. |

## Notes

- The public site renders without a database connection.
- Do not run `npm run db:migrate` against a database you do not own.
- There is no production deployment configuration in this repository yet.
